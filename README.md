# Unikart Ecommerce Project
An Ecommerce website built with Django, HTML, CSS, and JavaScript. 
Users can browse products, add items to cart, and place orders with COD or Razorpay payment.
## Features
- User authentication (login/signup)
- otp functionality
- Product listing and detail pages
- Shopping cart functionality
- Checkout with COD or Razorpay payment
- Admin dashboard for managing products
- Responsive design
